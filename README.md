# Rum Runner's Revenge

A **2D pixel art platformer** built in Unity (C#), featuring an advanced hierarchical finite state machine for player and enemy AI. **Nominated for TIGA Awards 2024.**

## Overview

Rum Runner's Revenge is a pirate-themed 2D platformer developed as a studio project at Bournemouth University. I served as **CEO and Lead Developer**, managing a multi-disciplinary team of artists, designers, and programmers. The project was recognised with a nomination at the TIGA Awards 2024 for quality and innovation in student game development.

## Features

- **Hierarchical Finite State Machine** — Advanced AI architecture for both player and enemy behaviour, enabling complex state transitions and nested state logic
- **2D Pixel Art Style** — Hand-crafted pixel art with smooth animations
- **Combat System** — Melee and ranged combat with weapons and projectiles
- **Enemy AI** — Multiple enemy types with state machine-driven behaviour that reacts to player positioning
- **Tile Map Levels** — Hand-designed levels using Unity's tilemap system
- **Level Interactables** — Environmental interactions and hazards (including instant-kill zones)
- **Particle Effects** — VFX for combat feedback and environmental atmosphere

## Tech Stack

- **Engine:** Unity
- **Language:** C#
- **Version Control:** GitHub
- **Project Management:** ClickUp, Microsoft Teams

## Code Architecture

```
Assets/_SCRIPTS/
├── Core/               # Core game systems
├── Player Scripts/     # Player controller and state machine
├── Enemy Scripts/      # Enemy AI and behaviour states
├── Weapons/            # Weapon system
├── Projectiles/        # Projectile logic
├── Level Interactables/# Environmental interactions
├── Particles/          # VFX and particle effects
├── Generics/           # Reusable base classes
├── Interfaces/         # Abstraction contracts
├── Structs/            # Data structures
├── ScriptableObjects/  # Unity data assets
├── Data/               # Game data
└── Intermediaries/     # System bridges
```
