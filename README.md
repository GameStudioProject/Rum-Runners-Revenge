# Rum Runner's Revenge

A **2D pixel art RPG** built in Unity (C#), featuring an advanced hierarchical finite state machine for player and enemy AI. **Nominated for TIGA Awards 2024.**

## Overview

Rum Runner's Revenge is a pirate-themed 2D RPG developed as a studio project at Bournemouth University. I served as **CEO and Lead Developer**, managing a multi-disciplinary team of artists, designers, and programmers. The project was recognised with a nomination at the TIGA Awards 2024 for quality and innovation in student game development.

## Features

- **Hierarchical Finite State Machine** — Advanced AI architecture for both player and enemy behaviour, enabling complex state transitions and nested state logic
- **2D Pixel Art Style** — Hand-crafted pixel art with smooth animations
- **Combat System** — Melee and ranged combat with enemy AI that reacts to player positioning and behaviour
- **Exploration** — Interconnected environments with NPCs, dialogue, and loot

## Tech Stack

- **Engine:** Unity
- **Language:** C#
- **Version Control:** GitHub
- **Project Management:** ClickUp, Microsoft Teams
